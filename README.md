# TailorTrack - Tailor Shop Management System

TailorTrack ek web application hai jo tailor shops ke customer details, orders, aur order status ko manage karne ke liye banaya gaya hai.

## 🚀 Features
- **Add Customer:** Naye customers ki details save karein.
- **Add Order:** Customers ke liye naye kapde/orders book karein.
- **Customer Details:** Sabhi customers aur unke orders ki jankari dekhein.
- **Order Status:** Orders ka live status track karein.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Django
- **Database:** SQLite / MySQL
